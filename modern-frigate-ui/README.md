# Modern Frigate UI

A mobile-first interface for Frigate NVR, served through Home Assistant Ingress.

- Fast home screen with lightweight camera previews
- Immersive camera viewer with a proper NVR scrub timeline
- Activity feed with object, camera and zone filters
- Per-user favorites and layout preferences

Open the **Cameras** panel in the Home Assistant sidebar after starting the add-on.
No Frigate credentials or tokens are needed; see [DOCS.md](DOCS.md) for configuration.
